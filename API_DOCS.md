📖 Predator Tracker API DocumentationDokumen ini mencatat seluruh integrasi pihak ketiga (Third-Party Services) yang digunakan dalam arsitektur Predator Tracker.

1. 🔗 Core Blockchain & Webhook EngineHelius RPC: Digunakan untuk menangkap transaksi di jaringan Solana secara real-time via Webhook. Digunakan juga untuk audit Insider Risk (Top 10 Holders). Alchemy: Digunakan sebagai mesin radar untuk jaringan EVM (Ethereum & Base) via Webhook. Integrasi dilindungi dengan verifikasi signature HMAC-SHA256.
2. 📊 Market Intelligence & Security ScannerDexScreener API: Digunakan untuk mengambil data harga USD, jumlah likuiditas, Fully Diluted Valuation (FDV), dan umur token (pair age) secara dinamis. RugCheck API: Digunakan sebagai satpam keamanan otomatis untuk mendeteksi risiko smart contract seperti Mint, Freeze, dan LP Burn status pada jaringan Solana.
3. 🛡️ Infrastructure & SecurityUpstash Redis: Digunakan untuk manajemen Rate Limiting (Anti-DDoS) pada formulir "Add Wallet" guna mencegah serangan spamming ke database. Clerk: Digunakan untuk menangani seluruh proses autentikasi user, pendaftaran, dan manajemen sesi. Neon DB (Postgres): Database utama serverless yang dikelola melalui Prisma ORM untuk menyimpan profil user, data paus, dan riwayat transaksi.
4. 💳 Monetization & CommunicationMoonPay Webhook: Digunakan untuk mengelola sistem langganan otomatis. Menangani upgrade tier (Scout, Predator, Apex) dan downgrade otomatis saat langganan batal. Proteksi keamanan menggunakan moonpay-signature-v2. Telegram Bot API: Digunakan sebagai antarmuka notifikasi utama untuk mengirimkan sinyal Alpha Alert dan laporan performa paus langsung ke HP user.

# predator-tracker — AI Agent Context

## Apa ini?
Whale Tracking Dashboard untuk Solana, Ethereum, dan Base blockchain. Memantau transaksi besar (whale) secara real-time.

## Stack
- Framework: Next.js (App Router)
- Blockchain data: Solana RPC, Etherscan API, Basescan API
- Charting: Recharts
- Deploy: Vercel

## Rules untuk Agent
1. Repo ini **standalone** — tidak terintegrasi dengan ekosistem pjtech-autonomous
2. Data blockchain bersifat real-time, pertimbangkan rate limit API
3. Cek `src/` untuk komponen utama
